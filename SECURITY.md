# Security policy

## Supported versions

During 0.x only the latest release of each `@inktrapjs/*` package gets fixes.

## Reporting a vulnerability

Please don't open a public issue. Report it privately through
[GitHub's "Report a vulnerability"](https://github.com/TanguiLouedec/inktrap/security/advisories/new)
form, with steps to reproduce and the affected version. You'll get a reply within a week.

Published packages are built and released only from GitHub Actions with npm provenance, so you
can check that a tarball came from this repository with `npm audit signatures`.
